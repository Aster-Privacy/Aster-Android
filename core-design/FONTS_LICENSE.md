# Bundled fonts

Every font in `src/main/res/font/` is licensed under the SIL Open Font License 1.1
(https://openfontlicense.org) and was taken from https://github.com/google/fonts.
Each file is a latin + latin-extended subset; variable families are clamped to the
weight range 400-700.
